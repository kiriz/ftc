## Team roles

Everyone helps everywhere, but each student usually has a main role.

| Role | What you do |
|---|---|
| Builder | Design and build the robot |
| Programmer | Write the code for the autonomous period and for driver control |
| Portfolio and outreach | Write the engineering portfolio and share what the team does with others |
| Drive team | 2 drivers control the robot in matches; 1 drive coach watches the field and guides them |

## What a practice looks like

The team will set its practice schedule (to be announced). A practice will usually include:

1. A short check-in on goals for the day.
2. Work in role groups: building, programming, portfolio.
3. Driving practice once the robot can move.
4. Notes on what was done, for the engineering portfolio.

## Student commitments

- Come to practices and events, or tell your coach ahead of time if you cannot.
- Show Gracious Professionalism: compete hard and treat other teams with respect.
- Keep notes on your work for the engineering portfolio.
- Wear safety glasses while building.

## How to learn programming

FTC robots are programmed in one of three ways:

| Tool | What it is | Good for |
|---|---|---|
| Blocks | Drag-and-drop code blocks in a web browser | Beginners |
| OnBot Java | Java code written in a web browser, no install needed | Moving on from Blocks |
| Java in Android Studio | Full Java with a desktop development tool | Experienced programmers |

Suggested path:

1. Start with Blocks to learn how the robot's motors and sensors work.
2. Move to OnBot Java once you are comfortable.
3. Move to Android Studio only if the team needs it.
