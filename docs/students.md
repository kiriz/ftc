## Team roles

Everyone helps everywhere, but each student usually has a main role.

| Role | What you do |
|---|---|
| Builder | Design and build the robot |
| Programmer | Write the code for the autonomous period and for driver control |
| Portfolio and outreach | Write the engineering portfolio and share what the team does with others |
| Drive team | 2 drivers control the robot in matches; 1 drive coach watches the field and guides them |

## How to learn programming

FTC robots are programmed in one of three ways:

- Blocks
- OnBot Java
- Java in Android Studio

The [FTC programming documentation](https://ftc-docs.firstinspires.org/en/latest/programming_resources/index.html) explains each one.

## Free learning resources

- [Skill Builders lessons](https://training.firstinspires.org/courses/ftc-skill-builders-26-27): official FIRST lessons for this season.
- [FTC programming documentation](https://ftc-docs.firstinspires.org/en/latest/programming_resources/index.html): official guides for Blocks, OnBot Java and Android Studio.
- [Game Manual 0](https://gm0.org): a community guide to building and programming FTC robots.
